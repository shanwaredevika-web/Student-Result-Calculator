# Student Result Calculator

A simple web-based Student Result Calculator built using HTML, CSS and JavaScript.

## Features

- Enter student name
- Enter marks for 5 subjects
- Calculate total marks
- Calculate percentage
- Display grade
- Display Pass or Fail result
- Validate marks between 0 and 100
- Clear all entered data
- Responsive design for smaller screens

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works

1. Enter the student's name.
2. Enter marks for five subjects.
3. Click the "Calculate Result" button.
4. The application calculates the total marks and percentage.
5. It displays the student's grade and Pass/Fail status.

## Live Demo

The project is deployed using GitHub Pages.

## Project Structure

- `index.html` - Structure of the webpage
- `style.css` - Styling and responsive design
- `script.js` - Result calculation and validation logic
